> **This image has a new name: [`joanfabregat/db-s3-backup`](https://hub.docker.com/r/joanfabregat/db-s3-backup).** It now backs up PostgreSQL as well as MySQL and MariaDB, hence the new name.
>
> **`joanfabregat/mysql-s3-backup` is still supported.** Every release is published under both names, with the same digest and the same tags, so an existing deployment keeps working and switching names is optional.
>
> **`latest` is now v5.** v5 reads a v4 configuration the same way, with three exceptions listed in the [upgrade notes](https://github.com/joanfabregat/db-s3-backup#upgrading-from-v4). To stay on v4, use `joanfabregat/mysql-s3-backup:v4`.
